# ResT signature verification

Python training code and results for the GPDS 32-pair experiment. See [COLAB_GPDS_32PAIRS_README.md](COLAB_GPDS_32PAIRS_README.md) for the supplied experiment notes and [requirements.txt](requirements.txt) for dependencies.

The source archive also contained a signature-image dataset (`archive (3).zip`), pretrained weights (`ViT-B_16.npz`), and a trained checkpoint (`checkpoints/rest_gpds_32pairs_10epochs_best.pt`). These large files are not included in this repository. The notebook referenced in the supplied notes was not present in the archive.
